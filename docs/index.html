CrawlerNest

A university ranking data platform you run yourself. Crawlers ingest ranking sources into a PostgreSQL warehouse, and an explainability-first web UI lets you browse, compare, and shortlist universities — with the evidence behind every number.

Why CrawlerNest

University rankings shape real decisions, but each publisher measures different things with different methodologies — the same university can sit at #4 in one ranking and #20 in another. Presented as a single number, a ranking hides that disagreement; presented side by side, it becomes evidence you can actually reason about.

CrawlerNest is deliberately not another ranking publisher. It is the infrastructure underneath: a platform that resolves universities from multiple sources into one canonical identity, aggregates their ranks with a documented formula, and shows you exactly which sources contributed, how much they disagree, and what data is missing. The name is literal — a nest where source crawlers live together and feed one shared, traceable warehouse.

Evidence over authority Every rank links back to the source records that produced it. Rank spread and source coverage are always visible.
Honest by contract Every analytics response carries a mandatory caveats list. Known limitations are disclosed, never softened for presentation.
No black-box scores Confidence is derived mechanically from source count. Aggregation weights are documented and stable — nothing is hand-tuned.
Explainable before intelligent The decision layer is deterministic and reproducible first; AI capabilities are layered on only where they can be evaluated.

What it does

  • Global & subject rankings — aggregated into a single warehouse with canonical university identities
  • Source comparison — per-university side-by-side ranks, rank spread, and confidence derived from coverage
  • Analytics — rank trends, cross-source disagreement, and data-quality diagnostics, each with its caveats attached
  • Recommendations — deterministic, evidence-backed shortlisting with exportable plans
  • Run it yourself — the repository ships with no data; your deployment crawls its own, politely (10s request spacing by default)

Quick start

./scripts/setup_from_scratch.sh   # venv, PostgreSQL, schema, first crawl
./scripts/start_localhost.sh      # API :8080 + web :3000

Then open http://localhost:3000/rankings. Prerequisites and the manual step-by-step are in GETTING_STARTED.md.

Bring your own data. No ranking data is bundled. The pipeline crawls sources live with polite defaults — review each source site's robots.txt and terms of use before raising crawl volume, and keep your data local unless the source's license permits redistribution.
