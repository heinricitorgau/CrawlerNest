CrawlerNest

An open-source university ranking data platform. Python crawlers ingest ranking sources into a PostgreSQL warehouse, a Spring Boot API serves aggregated read-only data, and a Next.js frontend lets you browse, compare, and shortlist universities.

View on GitHub

What it does

  • Global & subject rankings — aggregated into a single warehouse with canonical university identities
  • Explainability first — every ranking shows its sources, confidence level, and known data caveats; no black-box scores
  • Analytics — rank trends, cross-source disagreement, and data-quality diagnostics
  • Run it yourself — the repository ships with no data; your deployment crawls its own, politely (10s request spacing by default)

Quick start

./scripts/setup_from_scratch.sh   # venv, PostgreSQL, schema, first crawl
./scripts/start_localhost.sh      # API :8080 + web :3000

Then open http://localhost:3000/rankings. Prerequisites and the manual step-by-step are in GETTING_STARTED.md.

Bring your own data. No ranking data is bundled. The pipeline crawls sources live with polite defaults — review each source site's robots.txt and terms of use before raising crawl volume, and keep your data local unless the source's license permits redistribution.
