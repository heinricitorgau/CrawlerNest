# Report Lifecycle Documentation

This document defines the lifecycle, producer, consumer, freshness expectation,
and archival expectation for every report in the CrawlerNest operational surface.

Its purpose is to prevent report lifecycle confusion: which reports are
regenerated every run, which are point-in-time, which should be archived, and
which are permanently historical.

---

## Lifecycle Categories

| Category | Meaning |
| --- | --- |
| **ephemeral** | Regenerated every maintenance run; previous version is overwritten. |
| **operational** | Regenerated when the operator runs the relevant build script. Should be current before any demo or release. |
| **release-facing** | Copied into the release bundle at bundle-build time. The bundle copy is frozen; the live version may be updated afterward. |
| **historical** | Point-in-time evidence frozen at capture time. Never overwritten; accumulate over time. |
| **reference-only** | Structural or navigational artifact. Updated when the surface changes, not on a data schedule. |

| --- | --- |
| Producer | `scripts/build_demo_caveats.py` |
| Consumer | Demo presenters; release preparation operators |

### `snapshots/system_snapshot_*.json`

| Field | Value |
| --- | --- |
| Producer | `scripts/export_system_snapshot.py` (human-run) |
| Consumer | All operational report builders; historical comparison tools |
| Lifecycle | **historical** |
| Freshness expectation | Created by explicit operator invocation. New files are appended; old files are never deleted. |
| Archival expectation | Retain indefinitely (append-oriented). Cleanup per `docs/OPERATIONAL_CLEANUP_GUIDE.md`. |
| Release-facing | Named and latest copies go into release bundle |
| Criticality | **reference** (input to critical reports) |

| Archival expectation | Not archived. Overwritten on each snapshot export. |
| Release-facing | Copied into release bundle as input evidence |
| Criticality | **reference** (critical input to operational reports) |

### `releases/v0.1-demo/*.md` (bundle copies)

| Field | Value |
| --- | --- |
| Producer | `scripts/build_demo_bundle.sh` |
| Consumer | Demo recipients; release reviewers |
| Lifecycle | **historical** (frozen at bundle-build time) |
| Freshness expectation | Accurate at bundle-build time only. After the bundle is created, live `reports/` files are authoritative. |
| Archival expectation | Retain as the versioned release evidence. Do not update bundle copies after creation. |
| Release-facing | These are the release-facing copies |
| Criticality | **reference** for ongoing ops (critical only for the specific release being evaluated) |

## Lifecycle Patterns Summary

| Pattern | Reports |
| --- | --- |
| Regenerated on every `maintenance_overview.sh` run | `operational_trust_summary`, `operational_index_summary`, `maintenance_calm_summary`, `maintenance_navigation` |
| Regenerated on explicit operator action | `freshness_escalation`, `drift_timeline`, `operational_summary`, `demo_caveats`, `maintenance_readiness_summary` |
| Point-in-time, never overwritten | `snapshots/system_snapshot_*.json` |
| Frozen at bundle-build time | `releases/v0.1-demo/*` copies |
| Grows as history accumulates | `snapshot_timeline.md/json` (content), `snapshots/` (files) |
