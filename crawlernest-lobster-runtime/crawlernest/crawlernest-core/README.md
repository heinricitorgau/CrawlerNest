# crawlernest-core

Shared configuration, logging, models, and utilities.

## Files
- `config.py`: Central configuration management.
- `models.py`: Data models for Universities and Admission Requirements.
- `utils.py`: Re-exports utilities from the `utils/` package.
- `utils/`: Core utility modules (cache, formatters, logging, retry).
- `constants/`: Reference data (countries, regions, subject presets).
